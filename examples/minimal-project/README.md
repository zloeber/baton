# Minimal Baton example project

A tiny non-git project used by docs and tests. It contains:

- `.baton/config.json` — initialized config (safe, shareable defaults)
- `.baton/handoffs/` — one synthetic **draft** handoff

Run from this directory:

```bash
baton handoff list
baton handoff show <id> --format md
```

All content here is synthetic and labeled as such; nothing is real evidence.
