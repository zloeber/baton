# Minimal Threadline example project

A tiny non-git project used by docs and tests. It contains:

- `.threadline/config.json` — initialized config (safe, shareable defaults)
- `.threadline/handoffs/` — one synthetic **draft** handoff

Run from this directory:

```bash
threadline handoff list
threadline handoff show <id> --format md
```

All content here is synthetic and labeled as such; nothing is real evidence.
